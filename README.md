# pr2nikulnik
# Практическая работа №2. CSS, адаптивная верстка и SCSS

Учебный проект по дисциплине «Технологии разработки программного обеспечения».  
Тема: **Организация стилей с помощью SCSS**.

## 📋 Описание результата

Адаптивный каталог учебных товаров на HTML и SCSS.  
На странице реализованы:

- Сетка каталога на **CSS Grid** (`repeat(auto-fit, minmax(220px, 1fr))`).
- Панель фильтров слева, на мобильном экране переносится над карточками.
- 12 карточек товаров из `dataset/catalog.csv`.
- SCSS-переменные из `dataset/theme.json` (цвета, радиус, отступы).
- Миксины: `container`, `surface-card`, `focus-ring`, `mobile`, `mobile-sm`.
- Компиляция SCSS → CSS через npm-скрипты.

## 🛠 Используемые технологии

- HTML5 (семантическая разметка)
- SCSS / Sass (переменные, вложенность, миксины, функции)
- CSS Grid + Flexbox
- Node.js + npm + пакет `sass`
- Git + GitHub Desktop
